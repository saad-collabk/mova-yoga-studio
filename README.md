# MOVA Yoga Studio

A responsive, bilingual website concept for MOVA, a yoga and mindful movement studio.

## Highlights

- Russian and English language options
- Home, class, instructor, and booking views
- Responsive layouts and optimized imagery
- Scroll based motion effects with GSAP and ScrollTrigger

## Built with

- HTML, CSS, and JavaScript
- GSAP and ScrollTrigger from jsDelivr
- Google Fonts

## Run locally

From this folder, run:

```sh
python -m http.server 8000
```

Then open `http://localhost:8000`.

The booking flow is a front end demonstration. It does not submit real bookings or process payments.
